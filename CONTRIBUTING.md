# Contributing

Open an issue describing the problem and a minimal fictional/redacted example. Do not upload private screenshots, credentials or participant data.

Useful contributions: live Azure smoke-test reports (model, date, region, redacted result), evidence-quality benchmarks, interaction-state coverage, accessible UI improvements and human-review export enhancements.

Run `python -m unittest discover -s tests -v`. Preserve strict demo/live separation, screen references, human review and uncertainty. Do not add automated compliance claims or synthetic user-test results. Discuss new network integrations before adding them. Share reproducible findings and document limitations.
